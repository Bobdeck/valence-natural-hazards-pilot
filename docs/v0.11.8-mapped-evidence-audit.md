# SLS v0.11.8 · 56-cell mapped-evidence audit

This audit distinguishes *map evidence* from a point-based RAG determination. A published overlay, including a coarse inventory, is not a clubhouse clearance or a replacement for a scenario-specific rule. The RAG column records the unchanged v0.11.7 baseline. `Yes` in the Map column means the Site Detail hazard toggle connects at least one cited layer; it does not assert that a hazard polygon intersects the precise clubhouse point. ## Checked gaps

- Maketū coastal inundation: WBOPDC District Plan layer 18 returned no feature in a Maketū site envelope. Council published coverage identifies Waihī Beach, Bowentown and Pukehina, not a Maketū site result. An absence of live map is not an absence of hazard.
- Pāuanui flooding: TCDC's current stormwater model status schedules Pāuanui for 2028–2030. WRC local flood coverage does not cover the clubhouse; a broad regional query found a *Tairua* / Grahams Creek polygon but a tight Pāuanui clubhouse query returned zero. Do not mislabel the neighbouring catchment as a Pāuanui result.

Audit count: 56 site–hazard cells; 54 with an enabled mapped-evidence toggle and 2 explicitly unavailable. RAG states above are unchanged from the accepted v0.11.7 baseline.
